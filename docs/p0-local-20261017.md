## Scope and boundaries

Financial contracts and Docker execution are real; token/identity registries, model responses and fault injection are controlled. The economic command sequences explicit requests for one Agent and does not exercise an autonomous planner. Nonzero game subsidies, actual supplier costs, native-gas valuation, external customer demand and independent-team adoption are not established by these runs.

The consumer uses the packed SDK without importing repository source at runtime. Repository infrastructure still bootstraps Anvil, Underwriter, Relay and Arena. Publisher specification commitments are signed off-chain and admitted by the trusted operator; the existing escrow does not enforce a specification hash on-chain. This is a local integration sample, not a new production publication API.

The two GitHub workflow jobs now separate the lightweight review from local economic integration. Their commands passed locally; no new remote Actions run was triggered in this round. No commit, push, deployment, production business request, historical rewrite or saved-request migration was performed.
