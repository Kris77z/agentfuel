## Reproduction and maintenance

The [deployment bundle](../deploy/monad-vps/README.md) records the isolated users, ports, services, HTTPS proxy, offline migration and read-only verification commands. Bootstrap, runtime state, gateway journals and credentials are private operator files and are not served by nginx or included in the public repository.

Monad and Tempo share VPS hardware, with separate physical checkouts, Unix users, Node/Go installations, configuration, wallets, sessions and execution journals. Only nginx exposes HTTP/HTTPS; application services listen on loopback.

For maintenance, stop all three Monad units together because their `Upholds` dependencies reconnect the stack. Retain current business state when rolling back code; an old cold backup must not replace journals after new execution.
