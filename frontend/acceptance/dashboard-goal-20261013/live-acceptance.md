总计 20 次真实模型调用，20 个成功链上付款回执；账户现金由 0.60 降至 0.37 测试 USDC，债务保持 0。K2.6 每次调用价格为 0.01，K3 为 0.02；以上是目标任务的固定每次调用价格，token 用量另行记录。

所有脚本目标以原 UUID 重放，链上 nonce 与 Magpie 请求计数均未增加。失败任务保留实际消费，不将已交付的模型调用伪装为退款。

最终销售结果按“包括标点和 Markdown 的非空白 Unicode 字符”计数，371 ≤ 500。人工检查确认每月利润、毛利率、客单价、收入环比和季度汇总正确；没有额外日期或未经支持的因果断言。最终文本见 [live-sales-final.md](./live-sales-final.md)。

代码样例见 [live-code-artifact.md](./live-code-artifact.md)。额外的代码执行由验收人员在检查生成源码后完成，不表示产品的目标执行器具有 shell 或代码沙箱工具。当前目标执行器支持写作、基于输入的分析及代码生成；模型复验不等于外部事实核验。
